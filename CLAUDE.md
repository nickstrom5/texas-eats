## Sources (details and dates: `playbook/12-sources.md`)
- Statewide: TABC License Information (data.texas.gov 7hf9-qc9f, daily) and the Comptroller's Mixed Beverage Gross Receipts
  (naix-2893, monthly; **reported** alcohol sales per permit, shown as reported, never mixed with our estimates).
- Inspections, official scores only, as each city publishes them (never a grade of ours):
  - Austin (data.austintexas.gov ecmv-9xxi): score 0-100 + the dataset's own Green/Yellow/Red category.
  - El Paso (foodscores.elpasotexas.gov: one date-range search + the portal's own CSV download): score, 70 = passing.
  - Arlington (opendata.arlingtontx.gov ArcGIS OD_Community/7): latest score; the city's letter grades A/B/C/F.
- Not used: Dallas and Fort Worth (inspections.myhealthdepartment.com answers with a bot check), Houston (open data stops FY2015),
  San Antonio (sa.gov robots.txt blocks Claude; data.sanantonio.gov disallows /api/), DSHS (reCAPTCHA, no bulk list), appraisal
  districts (no clear redistribution terms).
- guide.michelin.com answers curl with a 202 bot challenge: never retried. The Texas list was read with Claude's web fetcher
  (robots allows it) into `data/research/michelin.json` (149: 19 one-star, 46 Bib, 84 Recommended; addresses read from each restaurant page 2026-10-20).

## Rebuild
```bash
.venv/bin/python pipeline/fetch_overture.py && .venv/bin/python pipeline/fetch_extras.py   # Overture places, outlines, address points
cd pipeline && ../.venv/bin/python listings.py                                             # stage1: clean + Google 2021 match
../.venv/bin/python geocode_official.py && ../.venv/bin/python geocode_census.py           # place TABC / El Paso records
../.venv/bin/python calibrate.py && ../.venv/bin/python texas.py && cd ..                  # web: site/texas.json
.venv/bin/python scripts/make-leaderboard.py                                               # site/index.html
```
The machine is shared: long jobs with `nohup … &` and `python -u`, one copy at a time. `geocode_official.py` indexes only the
address points some record needs (grouping all 11.5M took longer than the whole build).
